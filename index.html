일일작업등록 · 조립공정

대조립 BLK(예: 805)는 여러 중조립 BLK(805R1 · 805R2 · 805M1)로, 중조립은 여러 소조립으로 이뤄집니다. 중조립 BLK마다 소조립 입고 확인 → 입고 검사 → 중조립 → 품질검사를 거치고, 구성 중조립이 모두 합격하면 대조립 BLK에서 대조립 → 최종 품질검사를 진행합니다. 호선과 BLK NO만 넣으면 지금 등록할 공정이 자동으로 정해집니다.
1. 작업할 BLK
2. 현재 공정 위치
호선과 BLK NO를 입력하면 현재 진행 가능한 공정을 확인합니다.
3. 소조립 입고 확인
이 중조립에 들어갈 소조립이 모두 입고되었는지, 입고된 소조립에 이상이 없는지 확인합니다. 모두 입고되고 이상이 없어야 완료확인(입고 검사 요청)을 할 수 있습니다. 공정률은 입고 수량으로 자동 계산됩니다.

조립공정 등록 목록

작업일 · 호선 · BLK로 조회합니다. 공정(소조립 입고 · 중조립 · 대조립), 차수, 공정률, 투입 인원, 입고 · 치공구 기록, 품질 판정을 함께 확인합니다.

블록 구성 · 대조립 / 중조립 / 소조립

원청 블록 분할도의 대조립 번호(예: 805)를 기준으로, 그 안의 중조립(805R1 · 805R2 · 805M1)과 중조립마다 들어갈 소조립을 등록합니다. 이 구성으로 소조립 입고 확인 목록과 대조립 시작 조건(구성 중조립 모두 합격)을 판단합니다.

생산통합지표

일일작업등록과 검사 결과를 대조립 BLK 단위로 자동 집계합니다. 대조립(예: 805) 아래 구성 중조립(805R1 · 805R2 · 805M1)마다 소조립 입고 → 입고 검사 → 중조립 → 품질검사 중 어디에 있는지, 대조립을 시작할 수 있는지, 검사대기 · 재작업이 어디에 걸려 있는지, 어떤 부적합이 반복되는지, 작업 전 치공구가 준비되었는지 확인합니다.

게시판(공지사항)

전체 인원에게 전달하는 글입니다. 최근 글이 위에 표시됩니다. 수정 · 삭제는 본인이 쓴 글만 할 수 있습니다.

조립 품질검사

완료확인된 공정이 목록으로 표시됩니다. 소조립 입고 확인은 입고 검사, 중조립은 품질검사, 대조립은 최종 품질검사입니다. 검사할 건의 검사항목 열기를 누르면 체크리스트가 펼쳐집니다. 검사항목마다 적합 · 부적합 · 해당없음을 선택하고 종합 판정 의견을 적은 뒤 합격 또는 불합격을 저장합니다. 합격하면 다음 공정이 열리고, 불합격하면 같은 공정 재작업(입고는 보수 · 재입고)으로 돌아갑니다. 판정 결과는 작업등록자의 나의 업무 · 알림에 표시됩니다.
